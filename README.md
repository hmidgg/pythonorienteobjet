# Gumball TP

Petit projet Python autour de personnages et de situations chaotiques inspirées de l'univers de Gumball.

## Fonctionnalités actuelles

- Création de personnages avec une énergie et une humeur.
- Gestion de l'énergie et détection de l'épuisement.
- Création de situations : incendie, inondation et bêtise de Gumball.
- Calcul du chaos, du coût en énergie et de la réaction d'un personnage.

## Lancer le programme

Depuis le dossier du projet, exécutez :

```bash
python3 main.py
```

## Préparer l'environnement de développement

Choisissez un environnement Python, par exemple `venv`, Conda/Anaconda ou `pyenv` (avec `pyenv-virtualenv` pour gérer les environnements). Activez l'environnement choisi, puis installez `pytest` depuis le terminal :

```bash
pip install pytest
```

Nous utiliserons `pytest` pour les tests dans la suite du projet.
